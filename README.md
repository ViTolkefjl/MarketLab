# Маркет-Лаб Seller

Учебный тренажёр кабинета продавца маркетплейса. Разделы повторяют устройство Ozon Seller: Главная, Товары и цены, FBO, FBS, Продвижение, Аналитика, Финансы, Отзывы, Рейтинги. 16 миссий с пояснениями «как в настоящем кабинете».

Площадка, товары и все цифры вымышленные и учебные. Это не официальный продукт какого-либо маркетплейса.
